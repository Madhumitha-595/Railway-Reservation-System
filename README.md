# Railway-Reservation-System
A C++ railway reservation system using linked lists, queues, stacks, and binary search trees to manage passenger bookings, waiting lists, cancellations, and passenger searches.

## 📌 Project Overview
The Railway Reservation System is a menu-driven C++ application designed to manage passenger reservations, waiting lists, and ticket cancellations.

## ✨ Features
- Book railway tickets
- Store passenger details
- Manage waiting-list passengers
- Cancel reservations
- Search passenger records
- Display reservation details

## 🛠️ Technologies Used
- C++
- Data Structures and Algorithms (DSA)
- Linked List
- Queue
- Stack
- Binary Search Tree (BST)

## ⚙️ Data Structures
- **Linked List:** Stores passenger records.
- **Queue:** Manages waiting-list passengers.
- **Stack:** Maintains cancelled reservation records.
- **Binary Search Tree:** Supports passenger searching.

## ▶️ How to Run
Compile the source file using GCC:

```bash
g++ main.cpp -o railway.exe
```

Run on Windows PowerShell:

```powershell
.\railway.exe
```

Replace `main.cpp` with your actual source filename if necessary.

## 🎯 Objective
To demonstrate how C++ and data structures can be applied to railway reservation and passenger management.
